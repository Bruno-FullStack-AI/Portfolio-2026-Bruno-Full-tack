Sobre mim

Curiosidade para explorar.
Inteligência para construir.

Sou desenvolvedor Full Stack e Especialista em Inteligência Artificial. Uno engenharia, criatividade e visão de negócio para transformar ideias em produtos digitais inteligentes.

Minha trajetória conecta desenvolvimento web, automação, dados e Inteligência Artificial. Da mecatrônica à robótica — como no projeto com a Seara — aprendi que tecnologia só faz sentido quando resolve problemas reais de pessoas e empresas. Hoje aplico essa visão multidisciplinar para criar interfaces, sistemas e automações com IA.

Gosto de explorar problemas complexos, estruturar lógicas e usar IA para automatizar o que é repetitivo — liberando tempo para o que importa: estratégia e crescimento. Cada projeto é pensado para ser escalável, seguro e pronto para evoluir com o seu negócio.
